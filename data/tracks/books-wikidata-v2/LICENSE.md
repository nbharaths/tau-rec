# books-wikidata-v2 licensing

The factual source data in `catalog.json` and `source_selection.jsonl` is
derived from Wikidata, whose structured data is released under the Creative
Commons CC0 1.0 Universal Public Domain Dedication. τ-Rec also releases the
catalog-selection transform and the synthetic `formats` environment state in
these two files under CC0 1.0.

The frozen query-response bundle identified by `source_snapshot_asset.json`
contains Wikidata structured data and is distributed under the same CC0 1.0
terms.

- Wikidata licensing: <https://www.wikidata.org/wiki/Wikidata:Licensing>
- CC0 1.0 text: <https://creativecommons.org/publicdomain/zero/1.0/legalcode>

The task files, answer key, policies, manifests, and track documentation are
τ-Rec benchmark material released under CC BY 4.0, consistent with
`data/LICENSE`. Repository source code remains under the root MIT license.

Wikidata attribution is not required by CC0, but please credit “Wikidata
contributors” and cite τ-Rec when using this track.
